# Calcule Seu IMC

Calculadora de IMC simples, feita como parte de um desafio de 100 dias de código.

## Funcionalidades

Cálculo do Índice de Massa Corporal a partir do peso e da altura informados pelo usuário.

## Tecnologias utilizadas

HTML5, CSS3 e JavaScript.

## Como executar

Clone este repositório e abra o arquivo index.html no navegador.
